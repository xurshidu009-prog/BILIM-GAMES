# BILIM-GAMES
Bilim Games — o‘quvchilar uchun yaratilgan interaktiv ta’limiy o‘yinlar platformasi. Unda fanlar bo‘yicha testlar, xotira, to‘g‘ri/noto‘g‘ri, tezkor va maxsus o‘yinlar mavjud. Foydalanuvchilar natijalarini kuzatishi, do‘stlar qo‘shishi, reytingda qatnashishi, bellashuv o‘ynashi va AI ustozdan yordam olishi mumkin. Telefon uchun mos dizayn.
